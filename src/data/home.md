## Open By Design.

We focus on using ESPHome for integration with Home Assistant, one of the fastest growing and largest open-source projects on GitHub. If you ever want to write your own code, we'd never stop you. You can even grab the hardware design files in the docs. Things are still new around here so bear with us and raise an issue if you need any help.

## Install.

Your board ships with ESPHome on it. To start fresh, or to put the latest release on it, plug it in and use [Connect](#connect) in the rail. It flashes over USB from Chrome or Edge, straight from [vdbxio/esphome-configs](https://github.com/vdbxio/esphome-configs). For WLED use [install.wled.me](https://install.wled.me/).
